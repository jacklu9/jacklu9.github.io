1.1
Revision of basic mathematical concepts
Suppose we could inspect the ﬁeld everywhere around the capacitor. Recording the arrows would
be a beginning. We would still need to say how nearby readings diﬀer, how much crosses a surface,
and how the ﬁeld aligns with a path around a loop. These are diﬀerent questions; no single measure
of “ﬁeld strength” answers all of them. The operations below will let us ask each question without
losing its geometry. Purely mathematical examples use dimensionless coordinate numbers unless
units are stated; physical examples specify their quantities and units.
1.1.1
Vectors, ﬁelds, and diﬀerential operators
A ﬁeld is a map of values over space.
The measuring-probe map has a familiar counterpart:
place small wind sensors at many positions in a room and read them at the same instant. At
each position the sensor reports a speed and a direction. Drawing one arrow for each reading
gives a vector ﬁeld. The arrow starts at the sampling position; its length represents the measured
magnitude. It does not show where a particular air particle has travelled. An electric-ﬁeld map
has the same mathematical structure, although its arrows describe force per unit charge rather
than wind velocity.

A scalar is a single signed value, such as temperature or electric potential. A vector has components

ﬁeld assigns a vector. With Cartesian position coordinates x, y, z and time t, write

Here ˆx, ˆy, ˆz are unit vectors along the three perpendicular coordinate axes. The subscripts in
Fx, Fy, Fz identify components, not partial derivatives. Each component is itself a scalar ﬁeld. For
example, F = (−y, x, 0) means Fx = −y, Fy = x, and Fz = 0: at (1, 0, 0) its arrow points along
+y, while at (0, 1, 0) it points along −x.
A ﬁeld line is a curve whose tangent follows the ﬁeld direction at each point of one snapshot.
A trajectory records the positions occupied by an object as time passes. They coincide for par-
ticles carried by a steady velocity ﬁeld, but need not coincide for a changing velocity ﬁeld. An
electric-ﬁeld line is not generally the trajectory of a charged particle: the electric ﬁeld aﬀects its
acceleration, and its existing velocity matters.
The position vector r = xˆx + y ˆy + z ˆz tells us where we sample. The ﬁeld vector F (r, t) tells us
the value there. These vectors need not point in the same direction. A ﬁeld is uniform if its value
does not change with position, and static if it does not change with time. Thus xˆx is static but
nonuniform, whereas cos(ωt)ˆx is uniform but time-varying; ω controls the oscillation rate.

1.1.2
The gradient of a scalar ﬁeld
Some maps begin with numbers rather than arrows. Electric potential is one such map: before
it can tell us an electrostatic ﬁeld direction, we need to understand how a number changes as we
move. A contour map makes that question visible.
Read a contour map before calculating a derivative.
A scalar ﬁeld gives a value at every
location, but supplies no arrow of its own. For a ﬁeld on a plane, draw contours joining locations
with equal values. Walking along a contour changes position without changing the ﬁeld value.
Crossing contours changes the value. For equal contour increments, closely spaced contours mean
a larger change per unit distance.
One can also draw the scalar value as the height of a graph. That height axis represents the value
f, not a third physical position coordinate. The gradient of a two-dimensional ﬁeld is a direction
in the map’s plane: it tells us where to walk to make the graph rise fastest. For a physical three-
dimensional scalar ﬁeld f(x, y, z), the analogous equal-value objects are level surfaces, and the
gradient is a vector in physical three-dimensional space.
